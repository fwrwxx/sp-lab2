## 1. MPU-6050 (6-DOF IMU)

### 1.1. Загальна інформація

| Параметр | Значення |
|----------|----------|
| **Виробник** | InvenSense (тепер TDK) |
| **Модель** | MPU-6050 |
| **Тип** | 6-DOF IMU (3-axis accelerometer + 3-axis gyroscope) |
| **Кількість осей** | 6 |
| **Інтерфейс** | I²C (також підтримує SPI, але на GY-521 breakout — тільки I²C) |
| **Напруга живлення** | 2.375 – 3.46 В (MPU-6050), але GY-521 breakout має LDO на 3.3 В → приймає 5 В |
| **Споживання** | 3.9 мА (active), 5 µA (sleep) |
| **Корпус** | QFN-24, 4×4×0.9 мм |

**Datasheet:** [MPU-6050 Product Specification (PS-MPU-6000A-00)](https://invensense.tdk.com/wp-content/uploads/2015/02/MPU-6000-Datasheet1.pdf)
**Register Map:** [MPU-6050 Register Map (RM-MPU-6000A-00)](https://invensense.tdk.com/wp-content/uploads/2015/02/MPU-6000-Register-Map1.pdf)

### 1.2. Інтерфейс I²C

| Параметр | Значення |
|----------|----------|
| **Адреса (AD0=0)** | `0x68` (7-bit) → `0xD0` (write), `0xD1` (read) |
| **Адреса (AD0=1)** | `0x69` (7-bit) → `0xD2` (write), `0xD3` (read) |
| **Швидкість** | до 400 kHz (Fast Mode) |
| **Лінії** | SDA, SCL (обидві з pull-up 4.7 кОм) |

**У проєкті:** AD0 = 0 (GND), тому адреса 0x68. Швидкість — 400 kHz для мінімізації latency.

### 1.3. Розводка пінів (GY-521 breakout)

| Пін модуля | Призначення | Підключення до Nucleo-C031C6 |
|------------|-------------|------------------------------|
| **VCC** | Живлення 5 В (через LDO → 3.3 В) | 5V |
| **GND** | Земля | GND |
| **SCL** | I²C clock | PB8 (I2C1_SCL) |
| **SDA** | I²C data | PB9 (I2C1_SDA) |
| **XDA** | Auxiliary I²C data (для зовнішнього магнітометра) | не підключено |
| **XCL** | Auxiliary I²C clock | не підключено |
| **AD0** | Адреса I²C: 0 → 0x68, 1 → 0x69 | GND (0x68) |
| **INT** | Переривання (data ready, FIFO overflow) | опційно → PA0 (EXTI) |

**Спеціальні піни:**
- **AD0** — керує молодшим бітом адреси;
- **INT** — програмується на різні події (data ready, motion detection, FIFO watermark);
- **XDA/XCL** — для підключення зовнішнього магнітометра (наприклад, HMC5883L) — **не використовується** у цьому проєкті.

### 1.4. Register Map (ключові регістри)

| Адреса | Назва | R/W | Призначення | Значення у проєкті |
|--------|-------|-----|-------------|---------------------|
| `0x6B` | `PWR_MGMT_1` | R/W | Керування живленням | `0x00` — wake up, clock = internal 8 MHz |
| `0x75` | `WHO_AM_I` | R | Ідентифікатор чіпа | Має повернути `0x68` |
| `0x1B` | `GYRO_CONFIG` | R/W | Діапазон гіроскопа | `0x00` = ±250 °/s |
| `0x1C` | `ACCEL_CONFIG` | R/W | Діапазон акселерометра | `0x00` = ±2g |
| `0x19` | `SMPLRT_DIV` | R/W | Дільник частоти семплювання | `0x09` = 100 Hz (при DLPF=1kHz) |
| `0x1A` | `CONFIG` | R/W | DLPF (Digital Low Pass Filter) | `0x03` = 44 Hz accel, 42 Hz gyro |
| `0x3B`–`0x40` | `ACCEL_XOUT_H` … | R | Дані акселерометра (6 байт) | — |
| `0x41`–`0x42` | `TEMP_OUT_H/L` | R | Температура | — |
| `0x43`–`0x48` | `GYRO_XOUT_H` … | R | Дані гіроскопа (6 байт) | — |

**Ідентифікація чіпа:** після подачі живлення прочитати `WHO_AM_I` (0x75) — має повернути `0x68`. Якщо ні — I²C не працює.

### 1.5. Живлення

- **MPU-6050 чіп:** 3.3 В, 3.9 мА (active);
- **GY-521 breakout:** приймає 5 В (є LDO на 3.3 В);
- **Можна живити від 3V3 pin Nucleo:** так, але тоді LDO не потрібен. **Рекомендую 5V** — стабільніше.

### 1.6. Чому саме цей датчик

- 6-DOF достатньо для pitch/roll без магнітометра;
- I²C @ 400 kHz — швидке зчитування (14 байт ≈ 0.3 мс);
- Дешевий (~$2);
- Широка документація та приклади.

**Альтернативи:**
- **GY-89 (10-DOF):** додає магнітометр і барометр — надлишково, дорожче;
- **LSM6DS3:** кращий, але дорожчий і менш документований;
- **BMI160:** сучасніший, але складніший у налаштуванні.

## 2. SG92R (мікросервопривід)

### 2.1. Загальна інформація

| Параметр | Значення |
|----------|----------|
| **Виробник** | TowerPro |
| **Модель** | SG92R |
| **Тип** | Аналоговий мікросервопривід з металевими шестернями |
| **Момент** | 2.5 кг·см при 4.8 В |
| **Швидкість** | 0.1 с / 60° при 4.8 В |
| **Кут обертання** | 0° – 180° |
| **Напруга** | 4.8 – 6.0 В |
| **Струм (idle)** | 10 мА |
| **Струм (stall)** | 700 мА |
| **Вага** | 9 г |

**Datasheet:** [TowerPro SG92R datasheet](http://www.ee.ic.ac.uk/pcheung/teaching/DE1_EE/stores/sg90_datasheet.pdf) (SG92R близький до SG90)

### 2.2. Інтерфейс PWM

| Параметр | Значення |
|----------|----------|
| **Частота PWM** | 50 Гц (період 20 мс) |
| **Мінімальний імпульс** | 500 мкс → кут 0° |
| **Середній імпульс** | 1500 мкс → кут 90° |
| **Максимальний імпульс** | 2500 мкс → кут 180° |
| **Роздільна здатність** | ~1° (залежить від таймера) |

**У проєкті:** TIM3 CH1 (pan) та TIM3 CH2 (tilt) з PSC=47, ARR=19999 → 50 Гц.

### 2.3. Розводка пінів

| Провід | Колір | Призначення |
|--------|-------|-------------|
| **VCC** | Червоний | +5 В |
| **GND** | Коричневий/Чорний | Земля |
| **Signal** | Оранжевий/Жовтий | PWM |

### 2.4. Живлення

- **Струм stall:** 700 мА × 2 серво = 1.4 А — **не можна живити від Nucleo 5V!**
- **Рекомендація:** окремий BEC (5V, 2A) або USB-адаптер;
- **У Wokwi:** живлення не проблема — симулятор не моделює струм.

### 2.5. Чому саме цей сервопривід

- Металеві шестерні (довговічність);
- Момент 2.5 кг·см — достатньо для легкої pan-tilt платформи;
- Стандартний PWM 50 Гц — легко генерується HAL;
- Дешевий (~$3).

**Альтернативи:**
- **MG90S:** металеві шестерні, момент 2.2 кг·см — майже те саме;
- **SG90:** пластикові шестерні — слабший;
- **DS3218:** потужніший (20 кг·см), але дорожчий і більший.

## 3. W25Q64 (SPI Flash)

### 3.1. Загальна інформація

| Параметр | Значення |
|----------|----------|
| **Виробник** | Winbond |
| **Модель** | W25Q64JVSSIQ |
| **Ємність** | 64 Mbit = 8 MB |
| **Організація** | 32768 сторінок × 256 байт; 2048 секторів × 4 KB; 128 блоків × 64 KB |
| **Інтерфейс** | SPI (Mode 0 або Mode 3) |
| **Максимальна швидкість** | 104 MHz (standard), 133 MHz (quad) |
| **Напруга** | 2.7 – 3.6 В |
| **Струм** | 4 мА (active read), 1 µA (power-down) |

**Datasheet:** [W25Q64JV datasheet (Winbond)](https://www.winbond.com/resource-files/w25q64jv%20revj%2003272018%20plus.pdf)

### 3.2. Інтерфейс SPI

| Параметр | Значення |
|----------|----------|
| **Режим** | Mode 0 (CPOL=0, CPHA=0) або Mode 3 (CPOL=1, CPHA=1) |
| **Частота** | до 104 MHz (у проєкті — ~5 MHz) |
| **Лінії** | SCK, MOSI, MISO, CS (NSS) |
| **CS** | Активний LOW — керується вручну через GPIO |

**У проєкті:** SPI1 на PA5/PA6/PA7, CS на PB6 (GPIO_Output).

### 3.3. Розводка пінів

| Пін модуля | Призначення | Підключення до Nucleo-C031C6 |
|------------|-------------|------------------------------|
| **VCC** | Живлення 3.3 В | 3V3 |
| **GND** | Земля | GND |
| **CS** | Chip Select (active LOW) | PB6 (GPIO_Output) |
| **DO** (MISO) | Data Out | PA6 (SPI1_MISO) |
| **DI** (MOSI) | Data In | PA7 (SPI1_MOSI) |
| **CLK** | Clock | PA5 (SPI1_SCK) |
| **WP** | Write Protect (active LOW) | 3V3 (не захищаємо) |
| **HOLD** | Hold (active LOW) | 3V3 (не використовуємо) |

**Спеціальні піни:**
- **WP#** — захист від запису. Якщо потрібен — керувати GPIO;
- **HOLD#** — призупиняє передачу. Зазвичай підтягнутий до VCC.

### 3.4. Register Map (ключові команди)

| Команда | Код | Призначення |
|---------|-----|-------------|
| `READ_STATUS_REG1` | `0x05` | Читання статусу (BUSY, WEL) |
| `READ_DATA` | `0x03` | Читання даних |
| `PAGE_PROGRAM` | `0x02` | Запис сторінки (256 байт) |
| `SECTOR_ERASE` | `0x20` | Стирання сектора (4 KB) |
| `BLOCK_ERASE` | `0xD8` | Стирання блоку (64 KB) |
| `CHIP_ERASE` | `0xC7` | Повне стирання |
| `WRITE_ENABLE` | `0x06` | Дозвіл запису |
| `WRITE_DISABLE` | `0x04` | Заборона запису |
| `JEDEC_ID` | `0x9F` | Ідентифікатор чіпа (має повернути `0xEF 0x40 0x17`) |
| `READ_UNIQUE_ID` | `0x4B` | Унікальний 64-бітний ID |

**Ідентифікація чіпа:** команда `JEDEC_ID` (0x9F) → має повернути `EF 40 17` (Winbond W25Q64).

### 3.5. Живлення

- **3.3 В, 4 мА (active), 1 µA (power-down);**
- **Можна живити від 3V3 pin Nucleo:** так (4 мА — не проблема).

### 3.6. Чому саме ця flash

- 8 MB — достатньо для траєкторії (1000 семплів × 16 байт = 16 KB);
- SPI @ 104 MHz — швидко;
- Стандартні команди — легко реалізувати;
- Дешевий (~$1).

**Альтернативи:**
- **W25Q128:** 16 MB — надлишково;
- **AT25SF041:** 512 KB — достатньо, але менш популярний;
- **SD-карта:** потрібен FAT32, складніше.

## 4. LCD1602 + PCF8574 (I²C дисплей)

### 4.1. Загальна інформація

| Параметр | Значення |
|----------|----------|
| **Модель** | LCD1602 (16×2 символів) + I²C-модуль PCF8574 |
| **Контролер** | HD44780 (сумісний) |
| **Інтерфейс** | I²C (через PCF8574) |
| **Адреса I²C** | `0x27` (за замовчуванням) або `0x3F` |
| **Напруга** | 5 В |
| **Струм** | 1 мА (без підсвітки), 20 мА (з підсвіткою) |

**Datasheet:** [PCF8574 datasheet (Texas Instruments)](https://www.ti.com/lit/ds/symlink/pcf8574.pdf)

### 4.2. Інтерфейс I²C

| Параметр | Значення |
|----------|----------|
| **Адреса** | `0x27` (типово) або `0x3F` |
| **Швидкість** | до 100 kHz (Standard Mode) |
| **Лінії** | SDA, SCL |

**У проєкті:** адреса 0x27 (потрібно перевірити I²C-scan).

### 4.3. Розводка пінів (I²C-модуль)

| Пін | Призначення | Підключення |
|-----|-------------|-------------|
| **GND** | Земля | GND |
| **VCC** | Живлення 5 В | 5V |
| **SDA** | I²C data | PB9 |
| **SCL** | I²C clock | PB8 |

### 4.4. Живлення

- **5 В, 20 мА (з підсвіткою);**
- **Можна живити від 5V pin Nucleo:** так (20 мА — не проблема).

### 4.5. Чому саме цей дисплей

- Простий, дешевий (~$2);
- I²C — 2 проводи замість 6;
- Широко документований;
- У Wokwi підтримується (`wokwi-lcd1602` з `pins: "i2c"`).

**Альтернативи:**
- **SSD1306 OLED:** яскравіше, але дорожче;
- **LCD2004:** 20×4 — більше, але не потрібно.

## 7. Зведена таблиця підключень

| Компонент | Пін Nucleo-C031C6 | Функція |
|-----------|---------------------|---------|
| MPU-6050 SCL | PB8 | I2C1_SCL |
| MPU-6050 SDA | PB9 | I2C1_SDA |
| LCD1602 SCL | PB8 | I2C1_SCL (спільна шина) |
| LCD1602 SDA | PB9 | I2C1_SDA (спільна шина) |
| SG92R (pan) signal | PA6 | TIM3_CH1 |
| SG92R (tilt) signal | PA7 | TIM3_CH2 (якщо є) |
| W25Q64 SCK | PA5 | SPI1_SCK |
| W25Q64 MISO | PA6 | SPI1_MISO |
| W25Q64 MOSI | PA7 | SPI1_MOSI |
| W25Q64 CS | PB6 | GPIO_Output |
| Кнопка B1 | PC13 | GPIO_Input (EXTI) |
| USART2 TX | PA2 | USART2_TX |
| USART2 RX | PA3 | USART2_RX |
| LD4 (світлодіод) | PA5 | GPIO_Output (конфлікт з SPI1!) |

> ⚠️ **Конфлікт:** PA5 використовується і для LD4, і для SPI1_SCK. У проєкті треба вибрати щось одне. **Рекомендація:** використати LD4 (PA5) для індикації, а SPI1 перенести на інші піни (PA5 → SPI1_SCK, PA6 → SPI1_MISO, PA7 → SPI1_MOSI). Це стандартний pinout.
